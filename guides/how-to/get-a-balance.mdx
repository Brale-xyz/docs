---
title: "Get A Balance"
description: "Query the stablecoin balance of an internal (custodial) address or the USD balance of a Plaid-linked bank address."
---

Use `GET /accounts/{account_id}/addresses/{address_id}/balance` for both address types. Balances require both `transfer_type` and `value_type`.

## Wallet balance

<Steps>
  <Step title="Prerequisites">
    - Get your `account_id`: [How to get your account_id](/guides/how-to/get-your-account-id)
    - Get a custodial `address_id`: list addresses and choose one with `type=internal`:

    ```bash
    curl --request GET \
      --url "https://api.brale.xyz/accounts/${ACCOUNT_ID}/addresses" \
      --header "Authorization: Bearer ${AUTH_TOKEN}"
    ```
  </Step>
  <Step title="Call the balance endpoint">
    Use your `account_id` and an internal `address_id`.

    `GET /accounts/{account_id}/addresses/{address_id}/balance`

    | Parameter       | Description                   | Example                      |
    | --------------- | ----------------------------- | ---------------------------- |
    | `transfer_type` | Blockchain network            | `solana`, `base`, `ethereum` |
    | `value_type`    | Token symbol (case-sensitive) | `SBC`, `USDC`, `PYUSD`       |

    ```bash
    curl --request GET \
      --url "https://api.brale.xyz/accounts/${ACCOUNT_ID}/addresses/${ADDRESS_ID}/balance?transfer_type=base&value_type=SBC" \
      --header "Authorization: Bearer ${AUTH_TOKEN}"
    ```
  </Step>
  <Step title="Review the response">
    ```json
    {
      "address": {
        "id": "2VcUIonJeVQzFoBuC7LdFT0dRe4",
        "address": "0xcdEA458750b9A8D6C4Ba8B3D68CE98Ba2330352A"
      },
      "balance": {
        "value": "45314.07",
        "currency": "USD"
      },
      "value_type": "SBC",
      "transfer_type": "base"
    }
    ```
  </Step>
</Steps>

## Plaid-linked bank balance

<Steps>
  <Step title="Prerequisites">
    - Get your `account_id`: [How to get your account_id](/guides/how-to/get-your-account-id)
    - Get the `address_id` of a bank account registered through Plaid. See [Create addresses through Plaid](/key-concepts/addresses#create-via-plaid-linked-bank-account).
  </Step>
  <Step title="Call the balance endpoint">
    | Parameter       | Value       |
    | --------------- | ----------- |
    | `transfer_type` | `ach_debit` |
    | `value_type`    | `USD`       |

    ```bash
    curl --request GET \
      --url "https://api.brale.xyz/accounts/${ACCOUNT_ID}/addresses/${ADDRESS_ID}/balance?transfer_type=ach_debit&value_type=USD" \
      --header "Authorization: Bearer ${AUTH_TOKEN}"
    ```
  </Step>
  <Step title="Review the response">
    ```json
    {
      "address": {
        "id": "34yknnMShvDbSW6tQg4HLlN41QO",
        "address": null,
        "account_number": "****1234"
      },
      "balance": {
        "value": "1250.42",
        "currency": "USD"
      },
      "value_type": "USD",
      "transfer_type": "ach_debit"
    }
    ```
  </Step>
</Steps>

- Brale uses Plaid's available balance when Plaid supplies it. Otherwise, Brale uses the current balance.
- Successful reads may be cached for up to 30 seconds.
- The balance is a point-in-time snapshot. It does not guarantee that an ACH debit will settle.
- Brale never returns the full bank account number. `account_number` is masked.
- Only Plaid-linked USD bank addresses support balance lookup. Bank addresses created through Direct bank entry do not.

For error responses, see [Get an address balance](/api-reference/brale/get-address-balance#errors).

<Note>
  Balance queries are supported for internal custodial addresses and Plaid-linked bank addresses. Other external addresses—including self-custody wallets and bank addresses created through Direct bank entry—do not expose balances through Brale.
</Note>

## Notes

- Always send both `transfer_type` and `value_type`; a custodial address can hold multiple tokens across chains.
- See [Value Types](/coverage/value-types) and [Transfer Types](/coverage/transfer-types) for supported combinations.
