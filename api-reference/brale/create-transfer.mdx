### `rtp_credit` errors

A request with `destination.transfer_type: "rtp_credit"` returns `400`:

```json Response (400)
{
  "code": "ValidationError",
  "status": 400,
  "type": "invalid_transfer_type",
  "values": [],
  "detail": "Invalid transfer type"
}
```

Brale does not create a Transfer for this request. Add `fednow_credit` to the destination bank Address, then resend the payout with `destination.transfer_type: "fednow_credit"` and a new `Idempotency-Key`. See [Migrate from `rtp_credit` to `fednow_credit`](/guides/fednow-outbound#migrate-from-rtp_credit-to-fednow_credit).
