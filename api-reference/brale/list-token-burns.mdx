```
GET /accounts/{account_id}/tokens/burns
```

Required scope: `self_attested_tokens:burn`.

Returns the list of burn orders for a tokenization account, newest first.

## Path parameters

| Name | Type | Description |
| --- | --- | --- |
| `account_id` | string | KSUID of the tokenization account. |

## Example request

```bash
curl --request GET \
  --url https://api.brale.xyz/accounts/{account_id}/tokens/burns \
  --header 'Authorization: Bearer <token>'
```

## Example success response

```json
{
  "data": [
    {
      "id": "2XyBurnKsuid000000000000000",
      "status": "completed",

      "source": {
```

## Example error response

```json
{
  "status": 403,
  "title": "Forbidden",
  "detail": "Account is not configured as a tokenization (self-attested) account."
```
