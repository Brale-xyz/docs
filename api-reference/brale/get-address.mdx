---
title: 'Retrieve an address'
description: 'Retrieves a single internal or external Address by `address_id`.'
openapi: 'GET /accounts/{account_id}/addresses/{address_id}'
---

Use the playground below to try this endpoint directly, or review the OpenAPI details in the right panel.

This endpoint returns a single internal (custodial) or external Address by its `address_id`. Use it to fetch the latest `status`, `address` value, and enabled `transfer_types`.

### Example request

```bash
curl --request GET \
  --url "https://api.brale.xyz/accounts/${ACCOUNT_ID}/addresses/${ADDRESS_ID}" \
  --header "Authorization: Bearer ${ACCESS_TOKEN}"
```

### Example response

```json
{
  "id": "2MhCCIHulVdXrHiEuQDJvnKbSkl",
  "type": "external",
  "name": "Example Bank",
  "status": "active",
  "address": null,
  "transfer_types": ["ach_credit", "same_day_ach_credit", "rtp_credit"]
}
```

<Note>
This endpoint is useful after creating an address whose capabilities may update asynchronously — for example, checking whether `rtp_credit` has been added to an external bank address after RTP eligibility is confirmed. See [Create external address for RTP](/key-concepts/addresses#create-external-address-for-rtp).
</Note>
