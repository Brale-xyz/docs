---
title: 'Get Token Transfer'
description: 'Retrieve a single tokenization transfer by ID.'
---

```
GET /accounts/{account_id}/tokens/transfers/{transfer_id}
```

Required scope: `self_attested_tokens:mint`.

## Path parameters

| Name | Type | Description |
| --- | --- | --- |
| `account_id` | string | KSUID of the tokenization account. |
| `transfer_id` | string | KSUID of the tokenization transfer to retrieve. |

## Example request

```bash
curl --request GET \
  --url https://api.brale.xyz/accounts/{account_id}/tokens/transfers/{transfer_id} \
  --header 'Authorization: Bearer <token>'
```
